# Linux 文件系统模拟器 · Simdisk

**基于 C++17 跨平台实现的 100MB 虚拟 Linux 文件系统与多用户权限模拟器**。

`simdisk` 是一个深入模拟经典 UNIX/Linux 文件系统底层数据结构（Superblock、Inode 索引节点、数据块位图、目录项）的教学与工程实验项目。工程支持多用户权限分级、文件读写锁定、多级目录树递归操作，以及宿主机文件系统与虚拟磁盘之间的双向互拷。重构版全面采用现代 C++17 与 CMake 跨平台标准，重构了跨进程共享内存 IPC 协议，并彻底解决了原版的内存泄漏与磁盘布局覆写问题。

---

## 核心设计与磁盘布局

虚拟磁盘在宿主机上映射为一个 100MB 的二进制文件，划分为严谨的扇区结构：

```
┌────────────┬─────────────┬─────────────┬─────────────┬──────────────────────────┐
│ 超级块     │ Inode 位图  │ 块位图      │ Inode 节点表│ 数据块区 (Data Blocks)   │
│ Superblock │ Inode Map   │ Block Map   │ Inode Table │ (文件实际内容存储区域)    │
└────────────┴─────────────┴─────────────┴─────────────┴──────────────────────────┘
```

* **模块化分层**：
  * `filesystem`：磁盘格式化、Superblock、Inode 分配与空闲数据块管理；
  * `auth`：用户鉴权、角色权限模型（root / system / user）与文件读写属主校验；
  * `commands`：标准 UNIX 风格指令集解析与执行；
  * `ipc`：跨平台共享内存抽象层（Windows `CreateFileMapping` / POSIX `shm_open + mmap`），采用纯 POD 定长二进制通信协议。
* **双向文件互拷（Host-Guest I/O）**：原生支持将宿主操作系统的文件导入虚拟磁盘，或将虚拟磁盘内的文件安全导出至宿主目录。
* **双运行形态**：
  * **控制台一体化模式 (`simdisk`)**：单进程交互式 Shell（推荐，稳定全功能）；
  * **C/S 架构模式 (`simdisk-server` + `simdisk-shell`)**：内核后台守护进程与独立 Shell 客户端通过共享内存高频通信。

## 指令集速查

| 指令 | 语法与示例 | 功能描述 |
| :--- | :--- | :--- |
| `info` | `info` | 查看虚拟磁盘总体容量、已用空间与 Inode 使用率 |
| `cd` | `cd <路径>` | 切换工作目录（支持 `/` 根目录、`..` 上级目录与绝对/相对路径） |
| `dir` | `dir` | 列出当前目录详情（权限、大小、创建时间、属主） |
| `md` / `rd` | `md <目录名>` / `rd <路径>` | 创建目录 / 递归删除目录 |
| `newfile` | `newfile <文件名> [内容]` | 创建文件（支持内联内容或多行交互式输入） |
| `cat` | `cat <路径>` | 读取并打印文件内容（执行文件只读权限校验） |
| `copy` | `copy <源路径> <目标路径>` | 虚拟文件系统内部复制文件 |
| `copy (入)` | `copy D:\local.txt /guest_dir` | 将宿主机文件拷贝至虚拟磁盘 |
| `copy (出)` | `copy /guest_file.txt D:\out` | 将虚拟磁盘文件导出至宿主机文件系统 |
| `del` | `del <路径>` | 删除指定虚拟文件并释放关联数据块 |
| `adduser` | `adduser <用户名> <密码> <角色>`| 注册新用户（仅限 root 管理员） |
| `check` | `check` | 强制将内存中的 Superblock 与缓存写入磁盘镜像 |

## 构建与运行

### 编译依赖
* **C++ 标准**：C++17 或更高版本
* **编译器**：GCC 9+、Clang 10+ 或 MSVC 2019+
* **构建工具**：CMake 3.15+

### 编译工程

```bash
# 生成跨平台构建工程
cmake -S . -B build

# 执行编译
cmake --build build
```

### 启动运行

```bash
cd build

# 启动单进程控制台模式
./simdisk
```

*首次启动时按提示输入 `Y` 初始化 100MB 虚拟磁盘。系统默认管理员账号为 `root`，默认密码为 `password`。*
